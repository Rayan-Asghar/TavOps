Overwrite HANDOFF.md (max 30 lines) with: what this session did, current state,
files touched, the exact next action with its done-condition, open questions.
Then update PROGRESS.md wherever facts changed (feature status, verified state,
decisions, next steps). Never append to either file. Never mark anything done
without saying how it was verified.
